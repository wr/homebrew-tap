# homebrew-tap

Homebrew casks for [Wells Riley](https://wells.ee)'s apps.

## Mojito

[Mojito](https://mojito.wells.ee/) expands `:emoji:`, `::symbol::`, and `:::gif:::` shortcodes into the real thing in any macOS text field.

```bash
brew install --cask wr/tap/mojito
```

Requires macOS 14 (Sonoma) or later. The app is signed, notarized, and keeps itself up to date via Sparkle, so `auto_updates` is on — Homebrew won't try to manage upgrades behind its back.
